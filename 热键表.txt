猫耳FM 热键表

主窗口
Enter：打开选中的项目
Ctrl+Enter：音频打开“下载本集”并勾选当前音频；剧集打开下载列表，默认全不选
Ctrl+Shift+Enter：下载该剧集；从音频打开只勾选并定位当前音频，从剧集打开默认全不选
Shift+Enter：查看选中音频的简介或广播剧详情
Alt+Enter：查看选中音频的评论
Alt+Shift+Enter：在网页中打开选中的音频或广播剧
Backspace：返回上一级；搜索结果页返回首页
菜单键 或 Shift+F10：打开选中项目的内容菜单

下载菜单（Alt+D 打开）
T：下载任务，恢复隐藏的任务窗口，保留进度和列表位置
S：下载设置，可浏览或输入默认下载路径，设置创建剧集文件夹、下载结果活动区域朗读、统一的下载提示音、隐藏完成后关闭窗口（默认开启）、Esc 隐藏（默认开启）；保存后用于新任务
Ctrl+Shift+X：在主窗口、播放窗口或下载任务窗口隐显下载任务；只在本程序内生效，不新建任务，不影响播放倍速

下载音频选择窗口
上、下方向键：选择音频；空格：勾选或取消勾选当前音频（移动光标不下载）
Alt+A：全选；Alt+U：全不选
Alt+S：选择当前集至列表末尾；Alt+E：取消勾选当前集至列表末尾（均包含当前项，不改变前面的项目）
Alt+L：下载路径；Alt+B：浏览下载路径
Alt+P：文件夹名带发布者标签，默认关闭；下载设置关闭“创建剧集文件夹”时此选项隐藏
Alt+N：正剧集数按数字编号命名，默认关闭；不足100集至少两位，100集及以上至少三位，按整剧正剧总集数决定
Alt+O：音频文件名按发布顺序数字编号命名，默认关闭；按一次获取的完整剧集列表位置，在文件名前加编号和空格，例如“01 原文件名”。至少两位，全剧有100项时为三位；单独下载、批量下载和只勾选部分均保留全剧原序号，可与 Alt+N 同时开启。无关联剧集的独立音频从01编号
Alt+D：开始下载，关闭选择窗口并打开任务窗口；Alt+C 或 Esc：关闭选择窗口
未设置默认路径时保存到主程序目录的“下载”文件夹。默认创建剧集子文件夹；关闭“创建剧集文件夹”后，文件直接保存到下载路径。
文件夹和文件使用列表原名，仅替换 Windows 不允许的字符；同名文件跳过，不覆盖。
启用数字编号后只替换第几集/第几期的数字，其余文字和扩展名保留，例如第一期改为第01期；百集剧改为第001期。

下载任务窗口
Tab：切换待下载、已下载、下载失败列表及操作按钮；失败列表仅在有失败或跳过项目时显示
鼠标右键、菜单键或 Shift+F10：待下载列表中，正在下载的音频可暂停/继续或取消，等待中的音频可取消；取消需以“是/否”确认
鼠标右键、菜单键或 Shift+F10：下载失败列表中打开重试菜单；R 重新开始选中的失败任务，A 全部开始所有失败任务，重试任务回到待下载列表
单集暂停会保留临时进度并继续下载后面的音频；全部继续不会解除单独暂停的项目
Alt+O：打开“下载路径”框中的目录，也就是存放剧集文件夹的位置，跟随浏览选择或手动输入的路径，未更改时打开默认下载目录；Alt+P：全部暂停或全部继续
Alt+C：停止下载，需确认，保留已完成文件；Alt+Q：全部取消，确认后仅删除本次任务生成的文件，原有文件不动，删除后无法恢复
Ctrl+Shift+X：隐显下载窗口；隐藏后下载继续、焦点返回主列表，可搜索和播放其他音频；也可从“下载 → 下载任务”恢复。隐藏按钮仍可通过 Tab 找到
Esc：默认隐藏下载任务窗口，可在下载设置中关闭；关闭后 Esc 恢复关闭确认。此选项不改变选择音频、设置和确认子窗口的 Esc 行为
有未完成任务（包括暂停、正在停止或清理）时隐藏“关闭”按钮；任务结束后可用 Alt+X 关闭。标题栏关闭或 Alt+F4 仍走停止确认，等待文件释放后关闭
Alt+A：本任务窗口显示时，完成后是否关闭，初始为关闭、仅影响本次任务；隐藏完成是否关闭使用下载设置中的独立选项，默认开启
每个音频下载成功或失败时，无论窗口显示或隐藏，均通过活动区域朗读一次“音频名称下载完成”或“音频名称下载失败：原因”；可在下载设置中用 Alt+R 开关，不占用字幕语音。跳过、取消和重复结果通知不触发此提示
所有任务结束后，无论窗口是否隐藏，都弹出“恭喜”完成统计；确认后按对应选项关闭或保留窗口。隐藏完成的额外活动区域提示可在下载设置中关闭，不影响完成弹窗
进行中的进度和准备状态仅显示在任务行内，不主动朗读；失败原因随失败结果提示，也可在失败列表查看。“播放下载提示音”（Alt+S）统一控制逐集成功和失败的音效，取消和同名跳过不播放
退出程序时，若有未完成任务会确认是否停止，保留已完成文件，清理未完成临时文件后再退出；程序退出后不会继续下载

账号菜单（Alt+A 打开）
L：展开“登录账号”，可选择账号登录或 Cookie 登录（仅未登录时显示）
O：退出当前登录账号，保留已保存账号（仅登录后显示）

账号管理
Alt+N：新增账号
Alt+E：编辑选中的账号
Delete 或 Alt+D：删除选中的账号（需确认；Delete 仅在账号列表中生效）
PageUp 或 Alt+U：选中账号上移一项
PageDown 或 Alt+J：选中账号下移一项
Ctrl+Home 或 Alt+T：选中账号移至最前
Ctrl+End 或 Alt+G：选中账号移至末尾
Alt+O：退出当前登录账号（仅选中当前登录账号时显示按钮并生效）
Alt+C：复制选中账号的 Cookie
Alt+X 或 Esc：关闭账号管理
Enter：在账号列表中登录所选账号，成功后返回主界面
移动后焦点跟随账号，顺序自动保存，不切换当前登录账号。
PageUp、PageDown、Ctrl+Home、Ctrl+End 仅在账号列表中用于排序，不影响播放界面的上一集、下一集快捷键。

评论窗口
Enter：打开选中评论的回复
Shift+Enter：查看选中评论详情
Backspace（退格键）：返回上一级评论列表
菜单键 或 Shift+F10：打开选中评论的内容菜单
Esc：关闭评论详情窗口

播放窗口
Q：切换并保存“播放结束后”的操作，依次为单曲循环、顺序播放、不播放；与设置菜单保持一致，由读屏原生提示当前模式。不播放表示播完当前音频后停止自动续播，不影响手动播放或切曲
鼠标右键、菜单键或 Shift+F10：打开播放操作菜单（上一集、下一集、快退、快进、跳转时间、倍速、播放结束后、朗读开关、过滤方案）；“播放结束后”与设置菜单、Q 键同步并保存
空格：暂停或继续播放；音频已结束且没有正在切换的音频时，从头重播当前音频（无操作语音提示）
PageUp（上翻页）：播放列表中的上一曲，仅在播放窗口生效
PageDown（下翻页）：播放列表中的下一曲；同步切换字幕、弹幕和字幕跳转列表，仅在播放窗口生效。上一曲/下一曲切换成功后，由读屏原生提示播报当前音频名称
左方向键：快退 5 秒（无操作语音提示）
右方向键：快进 5 秒（无操作语音提示）
上方向键：提高音量（无操作语音提示）
下方向键：降低音量（无操作语音提示）
D：临时开启或关闭当前音频的弹幕朗读（默认状态可在“设置”菜单调整）
F：开启或关闭本次播放窗口的字幕朗读，换集保留状态；关闭播放窗口后重新打开时，按“设置→默认朗读字幕”恢复
Ctrl+F：字幕朗读开启时，开启或关闭字幕过滤模式；字幕朗读关闭时不生效。同一播放窗口换集或单曲重播保留状态，关闭窗口后重新打开默认关闭；规则可在“设置→字幕过滤规则”中修改
Ctrl+J：仅在播放窗口且字幕朗读开启时，打开字幕时间偏移设置并聚焦编辑框；只影响本次播放窗口，换集保留，不修改默认设置
主键盘 1～0：字幕朗读开启时，切换到已存在的过滤方案并开启过滤模式；字幕朗读关闭时不生效，小键盘数字不用于切换
T：朗读当前播放时间
J：输入分.秒跳转到指定位置；也可点“按字幕跳转”，上下方向键选择字幕后按回车跳转。两种跳转成功后都会开始播放；输入超范围时即时通过读屏原生提示
R：打开字幕过滤规则（实验性功能），修改后保存即可生效
F9：切换到下一个音频输出设备，播报设备名称，包括“跟随系统”
Shift+F9：反向切换音频输出设备；临时选择不改动设置菜单中保存的默认设备
C：提高一档播放倍速
X：降低一档播放倍速
Z：恢复 1.0 倍速

详情窗口
Esc：关闭窗口
